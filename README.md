# 点问 · CSS Whisperer

一个运行在你浏览器里的 SillyTavern 小工具。**不懂 CSS 也能改主题**——
你只要在界面上**点一下想改的地方**，它就告诉你「这是哪块」、当场找出影响这里的
CSS，并生成一段**能直接发给 AI（ChatGPT / Claude 等）的提问**，你复制粘贴去问，
AI 就能给你好看的修改代码。

> 它是**翻译助手**，不是编辑器。它自己不改你的主题、不生成样式——
> 它把「我想改这里」翻译成 AI 听得懂的精确提问，把写好看代码的活儿交给 AI。

## 为什么做这个

小白改主题最大的痛点不是「不会写 CSS」，而是**「知道想改哪，却说不清那是什么、
对应哪段代码」**。点问就解决这一步：点一下 → 拿到位置 + 相关代码 + 现成提问。

## 怎么用

1. 点魔棒菜单 🪄 → **点问**
2. 点面板里的「🎯 点选界面上要改的地方」
3. 去点你想改的位置（消息气泡、头像、输入框、按钮……）
4. 面板显示「正在改：【消息气泡】」，多层时可用顶部面包屑选粗选细
5. 选「想改这里的哪个部位」（背景 / 文字 / 边框 / 尺寸和间距 / 图标 / 特效 / 自定义，可多选）→ 卡片当场展开「想怎么改」
6. 点「生成提问」→「📋 一键复制」
7. 把复制的内容粘到 ChatGPT / Claude，按它给的做法改你的主题

生成的提问会包含**三种做法**，方便你按能力选：
① 教你改哪个数值；② 找到原代码整段替换；③ 给你一段可加进「自定义CSS」的代码。
如果你点的地方**作者没设计过样式**，它会请 AI **从零生成新 CSS** 教你加进自定义CSS。

## 安装

### 通过 git 安装（推荐）

1. SillyTavern → Extensions → Install Extension
2. 粘贴本仓库 URL → 安装
3. 在 Extensions 列表启用「点问 CSS Whisperer」

> 也兼容 **TauriTavern（TT）** 等同步 SillyTavern 前端的衍生客户端：
> 它们的 `third-party` 扩展目录与 SillyTavern 一致，本扩展只读页面 DOM/CSS、
> 只写你的「自定义CSS」，不依赖后端，故同样可用。

### 手动安装

克隆到：
```
public/scripts/extensions/third-party/css-whisperer/
```

## 法律与隐私合规

点问对标社区广泛使用的「美化编辑脚本」，是纯本地的分析/翻译工具：

- ✅ 会在你操作的当下，**读取当前页面**的 CSS 用于分析你选中的这一个元素
- ✅ 生成的提问文字**完全由你手动复制**，是否发给 AI、发给谁，都由你决定
- ❌ **绝不**把任何主题 CSS 收集、分类、蒸馏成「知识库 / 映射库」
- ❌ **绝不**上传任何数据到任何服务器（本工具没有任何联网请求）
- ❌ **绝不**持久化存储作者的 CSS 规则文本——分析用完即弃
- ❌ **不修改**、不覆盖、不写入你的主题或任何 .css 文件

一句话：它只是帮你「看懂当前这一处、问对 AI」，看完即忘，不留、不传、不建库。

## 技术结构

```
css-whisperer/
├── manifest.json          # 扩展清单
├── index.js               # 入口（魔棒菜单按钮 + 初始化）
├── src/
│   ├── picker.js          # 点选系统（点哪高亮哪 + 层级放大缩小）
│   ├── semantic.js        # 区域识别（把元素翻译成"消息气泡"等中文名）
│   ├── analyzer.js        # CSS 分析（当场读、看完即焚）
│   ├── prompt-builder.js  # 生成给 AI 的提问（三种做法 / 从零生成）
│   └── editor.js          # 读写 ST 原生「自定义CSS」框
├── ui/
│   ├── panel.js           # 引导式问答面板
│   └── style.css          # 面板样式（磨砂 / Claude 两套皮肤）
├── README.md
└── LICENSE
```
